# aihub-slides

A skill for building **slide decks** and **documents** as one self-contained HTML file. AI Hub UI (`aihub-ui`) shows such a file in its canvas as a native slideshow (or a paged document) and exports it: decks to PowerPoint (.pptx), PDF and HTML; documents to Word (.docx), PDF, Markdown and HTML.

Themes: in AI Hub UI > Settings > Themes make a theme (colors and fonts) or import one from an existing .pptx, then mention it in a chat as `@theme:name`. The skill uses the theme's CSS variables.

The same files open in any browser; nothing here needs npm.
